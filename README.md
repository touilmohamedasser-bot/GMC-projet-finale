Health Tracker Pro 💪

Health Tracker Pro is a responsive web application that helps users monitor their health by tracking BMI, BMR, daily calorie intake, water consumption, workouts, and progress history. All data is stored locally in the browser using LocalStorage, allowing users to continue using the application without creating an account.

📌 Features
👤 User profile management
⚖️ BMI (Body Mass Index) calculation
🔥 BMR (Basal Metabolic Rate) calculation
🎯 Daily calorie goal based on activity level and fitness goal
🍽️ Meal and calorie tracker
💧 Daily water intake tracker with progress bar
🏋️ Workout completion tracker
📈 Progress history
🌙 Dark mode
⚠️ Smart health alerts
💾 Automatic data saving with LocalStorage

🚀 How to Run
Download or clone the project.
Open the project folder.
Double-click index.html or open it in your web browser.
Enter your name and create your profile.
Start tracking your daily health information.

No installation or external libraries are required.

📊 Health Calculations
BMI
BMI = Weight (kg) / Height² (m²)

BMI Categories:

Underweight: BMI < 18.5
Normal: 18.5 – 24.9
Overweight: 25 – 29.9
Obesity: BMI ≥ 30
BMR

Male

10 × Weight + 6.25 × Height − 5 × Age + 5

Female

10 × Weight + 6.25 × Height − 5 × Age − 161
Water Recommendation
Daily Water (ml) = Weight × 35
⚠️ Smart Alerts

The application displays alerts when:

Daily calorie limit is exceeded.
Water intake is below the recommended amount.
Workout has not been completed.
User profile has not been created.
